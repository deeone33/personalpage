Looking for one setting? Open Settings and type in the search field at the top of its menu. For everything the search bar can do, type help in it.

Signing in

Click the person icon in the row of small icons. Choose Create account, enter an email and a password (twice), then click the link in the confirmation email and sign in. The first time you sign in, a short setup guide walks you through the boxes you want; you can run it again from Settings → Layout & boxes. Everything you set up is saved to your account and is there on any device. Before you sign in, the page shows sample content so you can see what it looks like.

Weather & Location

The city you start with is a guess. Until you choose one, the page takes the city from the time zone your device is set to: a device on Swedish time gets Stockholm, one on Estonian time gets Tallinn. Your browser hands that over by itself, so there is no permission question, and your position and IP address are not used for it. It can therefore be the wrong city in the right country. The setup guide asks you to confirm or change it, and you can change it at any time:

There are two separate places to set a city:

  1. The weather tile shows the forecast for one city. Click the tile, type a city name, click a result, then press Use for the tile.
  2. The date and time at the top of the page uses a different city. Open the cogwheel icon → Settings → Date & time → Change, type a city, and click Use next to it.

Changing one does not change the other. A ! on the weather tile means a weather warning for the coming days (strong wind, heavy rain or snow, frost, heat); hover it or open the tile to read it. In the weather window you can also save more cities and switch between them.

Mail (Gmail)

This shows how many unread emails you have, without giving the site your Google password. It needs a small piece of free code pasted into your own Google account, once per inbox. It looks technical, but it is entirely copy and paste — follow every step below in order.

Is this safe, and is it allowed? Yes to both. The script is made with Google Apps Script, Google's own tool for this, and runs inside your Google account under your name. This site never gets your Google password and cannot sign in as you; it can only ask your script, and the script only answers when shown its secret token. The script counts your unread mail, lists sender, subject and first line of the latest unread ones, and can send an email to your own address if you switch on email notifications. It cannot delete or move mail, or write to anyone else. To stop it at any time, delete the project at script.google.com or remove its access at myaccount.google.com/permissions.
  1. Go to script.google.com and make sure you are signed in as the Gmail account you want to show (top right corner of the page).
  2. Click New project (top left).
  3. You will see some sample code already in the box. Click inside that box, press Ctrl+A (or Cmd+A on a Mac) to select everything, then press Delete.
  4. Click the button below to copy the correct code, then click inside the empty box and paste it (Ctrl+V or Cmd+V).
// Paste this whole file into your Apps Script project (replace what is there), then
// Deploy > Manage deployments > pencil > Version: New version > Deploy.
function out(text) {
  return ContentService.createTextOutput(text).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  try {
    return handle(e);
  } catch (err) {
    return out(JSON.stringify({ error: String(err && err.message ? err.message : err) }));
  }
}

function handle(e) {
  var p = PropertiesService.getScriptProperties();
  var token = p.getProperty("T");
  var given = e && e.parameter ? e.parameter.t : "";
  if (!token) {
    if (given) return out(JSON.stringify({ error: "Open this address in your browser with nothing after /exec to get your token." }));
    token = Utilities.getUuid();
    p.setProperty("T", token);
    return out(JSON.stringify({ setup: "Copy this token into the site (Settings, Gmail accounts). It is shown only once.", token: token }));
  }
  if (given !== token) return out(JSON.stringify({ error: "Wrong token" }));

  var since = parseInt(e.parameter.since, 10) || 0;   // seconds; the moment you pressed "Mark read" on the site
  var cache = CacheService.getScriptCache();
  var key = "m" + since;
  var hit = cache.get(key);
  if (hit) return out(hit);

  var email = Session.getEffectiveUser().getEmail();
  var items = GmailApp.search("in:inbox is:unread", 0, 20).map(function (t) {
    var msgs = t.getMessages();
    var m = msgs[msgs.length - 1];
    return {
      from: m.getFrom(),
      subject: m.getSubject(),
      snippet: m.getPlainBody().replace(/\s+/g, " ").slice(0, 200),
      ts: m.getDate().getTime(),
      link: "https://mail.google.com/mail/?authuser=" + encodeURIComponent(email) + "#inbox/" + t.getId()
    };
  }).sort(function (a, b) { return b.ts - a.ts; });
  var fresh = since ? GmailApp.search("in:inbox is:unread after:" + since, 0, 30).length : null;
  var text = JSON.stringify({ email: email, unread: GmailApp.getInboxUnreadCount(), fresh: fresh, items: items });
  cache.put(key, text, 120);
  return out(text);
}

// Lets the site email you its notifications. It can only write to this same Gmail address, and needs the token.
function doPost(e) {
  try {
    var p = PropertiesService.getScriptProperties();
    var token = p.getProperty("T");
    var d = JSON.parse(e.postData.contents);
    if (!token || d.t !== token) return out(JSON.stringify({ error: "Wrong token" }));
    MailApp.sendEmail(Session.getEffectiveUser().getEmail(), String(d.subject || "OmniTree").slice(0, 200), String(d.body || "").slice(0, 8000));
    return out(JSON.stringify({ sent: true }));
  } catch (err) {
    return out(JSON.stringify({ error: String(err && err.message ? err.message : err) }));
  }
}

// Run this once from the editor only if you lose the token and need a new one.
function resetToken() {
  PropertiesService.getScriptProperties().deleteProperty("T");
}
  1. Near the top of the script.google.com page, click the untitled project name and rename it to something like "Mail for my start page", then press Enter.
  2. Press Ctrl+S (or Cmd+S) to save.
  3. Click the blue Deploy button (top right), then New deployment.
  4. Click the small gear/pencil icon next to "Select type" and choose Web app.
  5. Set Execute as to Me, and Who has access to Anyone. This must say Anyone, not "Anyone with a Google account".
  6. Click Deploy.
  7. Google will ask you to authorize the script. Click Authorize access, choose your account. If you see a warning that says the app isn't verified, click Advanced, then Go to (unsafe), then Allow. This warning is normal — it is your own private script, seen only by you.
  8. You will now see a Web app URL ending in /exec. Click Copy next to it.
  9. Paste that address into a new browser tab and press Enter. The page will show some text containing a token — a long code in quotes. Copy that token now; it is only shown this one time. If you ever lose it, there are reset instructions inside the code itself.
  10. Go back to this site, open Settings (cogwheel icon) → Mail. Paste in a name (e.g. "Personal"), the web app address, and the token, then press Save Gmail accounts.
  11. Wait about a minute and your unread count will appear on the site.

To add a second inbox, repeat all of the steps above while signed in to that other Gmail account.

Using it: hover the mail tile for the latest unread subjects, click it for the list, and press Mark read to count only mail that arrives from now on.

Emails from this page (notifications by email, and the “new device signed in” warning) are sent by this same script to its own address. If you set the script up a while ago, replace its code with the code above and deploy it again (Deploy → Manage deployments → pencil → Version: New version → Deploy); the address and the token stay the same.

Stocks

Open Settings → Stocks. There are five ways to add stocks, funds, indexes or crypto:

  1. Search by name: type a company name such as Tesla in the first field. A list appears under it with the symbol, the full name and the exchange; press Add on the right one. The same company is often listed on several exchanges, so pick the one you actually hold. If you know the symbol (NVDA, or NASDAQ:NVDA), type it and press Add.
  2. Paste a list: paste a comma-separated list of symbols and press Import.
  3. Import a file: press Import a file and choose the CSV file you exported from your broker or portfolio site. The page looks for a column called Symbol, Ticker or ISIN, wherever it is in the file, and shows what it found so you can untick what you do not want before anything is added. Files that only have ISIN codes (common with Nordic brokers) work too: the codes are looked up and turned into symbols, and any that could not be found are listed so you can add them by name. Only the symbols are taken; amounts, prices and account numbers in the file are not read into the page and the file is not uploaded anywhere. An Excel file has to be saved as CSV first (File → Save as → CSV).
  4. Import a Google Sheet: in Google Sheets press Share, set it to Anyone with the link (Viewer), copy the link and paste it in the link field. The sheet needs the same kind of column as a file: Symbol, Ticker or ISIN, with the column names in the first row. To import another tab of the sheet, open that tab before you copy the link. This reads the sheet once; it does not keep following it.
  5. Import your TradingView watchlist:
    1. Go to tradingview.com and open any chart while signed in.
    2. Your watchlist is the panel on the right side of the screen.
    3. Click the ••• (three dots) at the top of that watchlist panel.
    4. Choose Advanced view (or Share), then turn on link sharing if it is not already on.
    5. Copy the link it gives you — it looks like https://www.tradingview.com/watchlists/12345678/.
    6. Paste that link into the link field (the same one as for a Google Sheet) and press Import.

In the box: each row has the price, a small chart and the day's change. Choose what the chart covers (today, the week, the month, or off) in Settings → Stocks; in a narrow box the price is cut short to make room for it. Sort with the dropdown, and click a stock for the full chart with recent news and chatter about it. Market hours: the small clock button at the top of the box shows whether the markets your stocks trade on are open. The clock has the box’s “up” color while the market most of your stocks are on is open and its “down” color while it is closed (the same colors and strength as the rest of the box, set under Settings → Appearance → Signal colors per box). Point at it for a small box with your main markets, or click it for all of them, lined up in columns: the market, how many of your stocks are on it, open or closed, how long until it closes or opens, and at what time on your own clock. Click a market there to see which of your stocks belong to it. Crypto is left out because it never closes; currencies and commodities (oil, gold) trade almost around the clock from Sunday evening to Friday evening. The page works out the market from the symbol (NASDAQ:NVDA, SAAB-B.ST); a symbol without an exchange is taken as a US stock. The main public holidays are counted, shortened trading days are not. Price alerts: the bell button next to the clock opens a small window where you fill in one sentence: Alert me when [stock] is [more than / less than / reaches] [price]. The price field starts at what the stock costs now. You get one notification when it happens and the alert then switches itself off; tick it to set it again, change its price or condition right in the list, or remove it with ✕. Set a price alert in the window of a stock opens the same thing for that stock. Up to 30 alerts; prices are looked at about once a minute while the page is open in a tab. Star or hide a stock in Edit mode.

Alerts: a notification when a stock moves fast (within about half an hour) or far on the day. Set the percentages in Settings → Notifications.

News & Telegram

Open Settings → News, Telegram & Reddit.

  • To add a news source: give it a name and either a feed address (for example https://feeds.bbci.co.uk/news/world/rss.xml) or just a website like reuters.com, and press Add. A feed address is the most reliable; with only a website the page looks the news up through search services. Up to 15 sources. Start the name with the outlet (“SVT Utrikes”, “BBC World”): two feeds whose names start the same count as one outlet.
  • To add a Telegram channel: type its name (for example ClashReport) or paste a t.me link, and press Add.
  • Click the ✕ next to any source to remove it, or Back to default sources to start over. The list also shows when each source last delivered, and why one was skipped.
  • Each of the News and Telegram tiles has its own Sources button, to temporarily hide one source without deleting it.

Reading the news: a story you have not seen gets an accent bar, and the header counts them (click the count to mark everything seen; being away for 2+ minutes does that automatically). Stories you opened are dimmed. The same story from several sources is one row with a source count before the time, also when one report is in Swedish and another in English; three or more outlets within 3 hours makes it hot. A story stays where it was first reported: another source picking it up joins the row and does not mark it new again. Hover a row for the picture and summary, click it for all sources. Search: the ⌕ button at the top of News, Telegram and Reddit opens a search field. It looks through everything the box has loaded (not only the rows on screen), in the headline or post text and the source name; every word you type has to be there, in any order, and capitals and accents do not matter. A moment later (or at once with Enter) it also looks further back than the box reaches: the last 30 days on your own news sites, the whole history of your Telegram channels, and the last year of your subreddits. What it finds joins the list, newest first. Press ⌕ again to close the search.

The reader: click a headline or post and it opens in a window with the other posts of that box above and below it, each one in full with its picture or video, so you scroll from one to the next instead of opening them one by one. Each post gets the window to itself: the list stops on one post at a time (a post longer than the window is scrolled through first), so two posts are never on screen together. The small list button at the top of the box (before ⌕) is for catching up: it opens the same window at the oldest post you have not seen, with a New line above it, and you scroll down to the newest, where it says you are up to date. A post counts as read once you have scrolled to it, so the count of new posts goes down as you read. On a phone the reader fills the screen and you scroll with your thumb; with a keyboard, ↓ and ↑ (or J and K) go one post on or back, and Esc closes it. The button beside Close shows which way the list runs (↓ Newer or ↓ Older) and turns it around. Videos do not start by themselves, and stop when you scroll away. In Telegram, Load older posts at the old end fetches more; in Reddit, Top comments shows the comments under a post. Under Settings → News, Telegram & Reddit → Reading posts you choose whether a click opens the reader or the single post, and which way scrolling down goes after a click and from the catch-up button. Scrolling in the reader moves switches between one post at a time and free scrolling, and Height of the reader window sets how much of the screen the window takes (90, 75, 60 or 50%; on a phone it always fills the screen).

Languages: under Languages shown in News tick the languages you read; headlines in other languages are left out (nothing is translated). How many: Headlines shown and Telegram posts shown set the length of the lists; the button at the end of a list shows 20 more, and for Telegram it also loads older posts.

Filters & alerts: Mute words hide every headline containing them; Highlight words mark matching headlines and notify you when a new one appears.

Twitch

Open Settings → Twitch → press Connect, log in if asked, and approve access. The box then shows who you follow that is live, with game and viewers; sort it or pick one category with the dropdowns. Hover a channel for a preview picture, the stream title and how long it has been live. Click a name to watch inside the page. Streamers you starred (Edit mode) who are offline are listed dimmed under the live ones with when they were last live; switch that off in Settings → Twitch.

Discover: the compass button at the top of the box (always there, also while people you follow are live) opens a window for everything you do not follow. It starts with the biggest live streams right now. Pick a category from the chips to see its ten biggest streams, with Show 10 more for the next ten; All categories unfolds the list and More categories loads further ones. Type in the field to search for a channel or a game by name, and choose a language to see only streams in it. Click a stream to watch it the usual way; the player has a Discover button to go back. ☆ puts a channel on your own list without following it on Twitch: it then shows in the Twitch box when it is live, among your ★ streamers when it is not, and you are told when it goes live. Nothing is asked of Twitch until you open the window, and each answer is kept for a minute. Discover needs your Twitch account to be connected.

Chat says “log in”, or ads even though you have Turbo or a sub? The player and chat inside this page are a Twitch “embed”. Your browser treats it as a third-party site and hides your twitch.tv login cookie from it, so Twitch thinks you are logged out: you cannot write in chat (the login window opens and closes again by itself) and you get ads. This is a browser setting, not a fault, and Connect in Settings does not change it. Two fixes:

  1. Pop out (works everywhere): press Pop out on a stream, or turn on Settings → Twitch → Open streams in a pop-out window. The pop-out is twitch.tv itself, so your login, Turbo and subs work. Allow pop-ups for this site if the browser asks.
  2. Let the embed see your login: allow third-party cookies for Twitch only. Quickest in Chrome and Edge: click the icon at the left end of the address bar while on this page and allow third-party cookies for this site. Or through the settings:
    • Chrome: Settings → Privacy and security → Third-party cookies → Sites allowed to use third-party cookies → Add → [*.]twitch.tv.
    • Edge: Settings → Cookies and site permissions → Manage and delete cookies → Allow → Add [*.]twitch.tv (and set Tracking prevention to Balanced, not Strict).
    • Firefox: Settings → Privacy & Security → Cookies and Site Data → Manage Exceptions → add https://www.twitch.tv and https://player.twitch.tv as Allow.
    • Brave: click the lion icon on this site → Advanced → Cookies: Allow all.
    • Safari: cross-site tracking prevention cannot be relaxed per site, so use Pop out.
    Then make sure you are logged in at twitch.tv in the same browser and reload this page.

Tip: mark streamers with ★ (Edit mode) to get a notification when they go live.

YouTube

This shows new uploads from channels you subscribe to (YouTube does not allow websites to read your personal recommended feed, so this is the closest available option).

  1. Go to takeout.google.com while signed in to your YouTube account.
  2. Click Deselect all (near the top).
  3. Scroll down, find YouTube and YouTube Music, and tick its checkbox.
  4. Click the button on that same row that says All YouTube data included. Untick everything, then tick only subscriptions.
  5. Click Next step, then Create export.
  6. Wait for an email from Google (usually a few minutes) and click the download link inside it.
  7. Open the downloaded file. Inside it, find a file named subscriptions.csv (it will be inside a "YouTube and YouTube Music" folder).
  8. On this site, open Settings → YouTube, click Choose subscriptions.csv, and select that file.

Radio

The small box next to the menu icons is an internet radio: pick a station from its list, press ▶ to play and ■ to stop; the speaker button opens a volume slider. It keeps playing while you use the rest of the page, and choosing another station while it plays switches straight to it. Tick which stations are in the list in Settings → Radio. Your own stations: in the same place, under Add a station of your own, type a station name, a city or a genre (BBC Radio 1, Stockholm, jazz). The list that appears comes from Radio Browser, a free public catalogue of tens of thousands of stations; ▶ lets you listen before you decide and Add puts the station in your list under “My stations”, ticked and ready in the box. You can also paste a stream address that starts with https://. Up to 25 of your own; ✕ next to one removes it. A station that is already in the list, also when the catalogue has it under another address, is not added a second time: it is ticked instead. The song that is playing shows for your own stations too, whenever the station sends it along with the music (most do; some only send their own name or nothing). A red play button means that station could not be reached just now. What is playing: press the ⓘ button after the volume button (or click the box itself; hovering it shows the song, artist and album cover) for the song with album, year, length, who wrote it, links to the song and lyrics, and the last five songs. Under them is a short note about the station: its genre, language and country, its sound quality, a few of its own tags and a link to its website, as far as the public station catalogue knows them. Not every station sends its song, and the earlier songs are the ones noted while the radio played on this page. (The currency converter that used to be here is now in the search bar: type 100 usd in eur.)

Timers, countdowns & stopwatch

Click the clock icon and choose Timer, Countdown or Stopwatch. A finished timer or countdown keeps ringing every few seconds until you press Stop or remove it, so it is hard to miss. You can set how loud it rings in Settings → Notifications → Alarm volume.

Notes & to-dos

Click the notepad icon (or use its shortcut). There are two tabs. To-do: type a task and press Enter; click the circle to tick it off (finished tasks move under Completed, which you can open or clear). Notes: write in the first card and press Save (or Ctrl+Enter). In both, click any text to edit it in place, and hover for pin ★ and delete ✕. The number on the icon is how many to-dos are open.

Quick ways to add one: type note buy milk or todo call the bank in the search bar and press Enter; or press Ctrl+V anywhere on the page (not in a text box) and choose As a note or As a to-do on the small card that appears (switch that off in Settings → Layout & boxes).

Reddit

The Reddit box shows posts from your subreddits. Add or remove them in Settings → News, Telegram & Reddit. In the box, choose Best, Hot, New, Top or Rising, and use Sources to hide a subreddit without removing it. Hover a post for a preview; click it for the text, the links and the top comments. How many comments are shown (3, 5, 10, 20 or none) is set in the same Settings section. Reddit only gives a flat list without votes, so the button in the window opens the full discussion.

Sports

Live scores and fixtures. Choose your leagues in Settings → Sports: football leagues and cups from more than twenty countries plus the World Cup, the European Championship and the Nations League, NBA, college basketball and football, NHL, NFL, MLB, rugby, cricket, Australian football, tennis, Formula 1, IndyCar, NASCAR, golf and UFC come from ESPN; SHL (Swedish hockey) comes from shl.se and Counter-Strike 2, League of Legends and Dota 2 from bo3.gg (those four need you to be signed in).

In the box: pick a sport and a view: Live & today, Upcoming, Results, Favorites, and ★ your favorite sport if you set one in Settings (everything on now, today and coming up in that sport). Hover a game for the short story of it; click it for goals and cards with minute and scorer, period scores, match stats, top performers and the league table with both teams highlighted. Every team sport also gets, where the source has it: who scored and when, the full team stats, the best player lines of each team (switch team with the two small buttons), football line-ups and the last five results of both sides, and before the game the odds and who is unavailable. A Formula 1 weekend shows the order of every session that has run (click a session) with the driver and team standings; golf shows the whole leaderboard round by round; tennis shows the world ranking under the matches. Rugby shows every try, conversion and penalty with the minute and the scorer (T, C, P, DG), the cards, both line-ups, the last five results and the table with bonus points; rugby league adds team stats. Cricket shows the result, the batting and bowling figures, the teams and the table with net run rate. Australian football shows the goals, the score of each quarter, team stats, the players with the most disposals and the ladder. IndyCar and NASCAR show the order of the race and the driver standings. SHL games show the goals with assists, the score of each period, team stats, the best skaters and the goalies. Esports matches show the last five results of both teams, their world ranking and recent meetings, and every map or game with its score: Counter-Strike 2 adds the players’ kills, deaths, assists and rating, Dota 2 a scoreboard for each game with heroes and net worth. Click a team’s name for the team: roster, career numbers, next matches, last results and titles; click a player in the roster for the player. An esports game hasWatch buttons that dock the Twitch stream showing it.

Results: choose Results in the view list to go back in time: finished games, fight cards, races and tournaments, newest first, with a small heading for each day. Click one for the same full details as a live game (a finished UFC card opens with every fight, and each fight with its numbers). Team leagues go back to the start of the month (in the first week of a month, the month before as well); UFC cards, Formula 1 weekends and golf tournaments four weeks; tennis, SHL and esports about a week. The list shows the 120 newest; pick one sport in the first list to see further back in that sport.

Search: press ⌕ at the top of the box and type a team, player, fighter, league or event. It looks through everything that is loaded for the leagues you follow, whatever the view: what is live, what is coming up this month and the recent results, in that order. Several words narrow it down (for example ufc allen). Press ⌕ again to close the search.

Favorites: press ☆ next to a team, fighter or player in a game's window. Favorites are marked ★ and listed first. You get a notification when their game starts, at every goal (football and ice hockey) and at the final score, and their games appear in the calendar (both can be switched off in Settings).

UFC: an upcoming event is one row; click it for the fight card, where the number after each name is the odds to win. While a card is on, every fight is its own row: the one in the cage first with round and clock, then what is next, then the results. Click a fight for both fighters side by side, the numbers of the fight (strikes, takedowns, control time) and a tale of the tape. Hover a fighter's name for a small card; click it for the fighter's own window.

TV shows

A box for the series you watch. It is off at first: switch it on under Settings → TV shows (or Layout & boxes).

Follow a show: press ⌕ at the top of the box, type its name and press ☆ on the right one. Up to 60 shows. The views: My shows: coming up lists the next episode of each show you follow, soonest first, under a heading for each day. Each row is kept to the show, the episode number and the time; point at a row for the episode’s title and the channel, or click it for everything; My shows: just aired lists the latest episode of each, newest first; On today shows the best-known shows airing today in one country, on television and on streaming services, with yours marked ★ (choose the country in Settings → TV shows).

Click a row for the show: what it is about, where it runs, its rating, the coming episodes with their dates and the latest ones with a short description, and a button to follow it or stop. The next and the latest episode of each show also sit on their day in the calendar, and you get a notification when a new episode goes on air; the first is switched off under Settings, TV shows and the second under Settings, Notifications. Times are in your own time zone. The list of shows you follow, with a button to remove each, is also under Settings → TV shows. Show information comes from TVmaze.com; films are not included.

Hiding boxes & docking

Hide a whole box: in Edit mode press Hide on it, or switch it off in Settings → Layout & boxes, where you can also switch it back on. A hidden box is not loaded. Dock notes or the calendar: open one and press Dock left or Dock right at the bottom; it then stays at the side of the page. Use ⇄ on a docked panel to move it to the other side and ✕ to turn it back into a window. Reload and problems: every list box has a ↻ button to reload it. When something in a box could not be loaded, a small ! appears next to it; click it to read what failed, why, since when, and what you can do. Read later: put a headline, Telegram post, Reddit post or video aside for later. With the mouse on its row, a small bookmark button takes the place of the time; or press Read later in the window that opens when you click the item (on a phone, that is the way). Saved rows keep a small bookmark mark. The list is the third tab of Notes: click an item to open it, press ✓ when you are done to take it off the list. It holds up to 100 items and is the same on all your devices. Bookmarks bar: a slim row of your own links at the very top of the page. Switch it on and add links under Settings → Bookmarks; group links in a folder (it opens as a small list), choose an icon and a color for each, and move them left and right with ◀ ▶. Bring your browser’s bookmarks along: first save them to a file in your browser (Chrome, Edge, Brave and Opera: Bookmark manager → ⋮ → Export bookmarks; Firefox: Bookmarks → Manage bookmarks → Import and Backup → Export Bookmarks to HTML; Safari: File → Export → Bookmarks). Then, under Settings → Bookmarks → Import from your browser, choose that file. Every folder in it is listed with a tick box and the number of links; tick the ones you want and choose for each whether it becomes a folder or separate links on the bar. The browser’s own bookmarks bar is ticked from the start. Links you already have are skipped, a folder takes 60 links at most, and the file is read on your device, not uploaded. Web page boxes: under Settings → Web page boxes you can show up to three web pages in boxes of their own, for example a dashboard, a live map, a webcam or a shared document. Paste the address and the box appears; move it with Edit like any other box, and change its height with H− and H+. The small arrow in its corner opens the page in its own tab, ↻ loads it again, and it can reload by itself every 1, 5, 15 or 60 minutes. Many large sites (Google, Facebook, banks, most news sites) do not allow being shown inside another page; then the box stays empty, and when you are signed in the settings tell you so as soon as you paste the address. Look for an “embed” address on such a site (usually under Share → Embed); those work. The page in the box cannot read anything from OmniTree and cannot take over the tab. Date, time and world clocks: under Settings → Date & time you tick what the top of the page shows (day name, date, year, time, location), choose the European or the American way of writing it, and set the font, size and color of the day name. Add up to five cities there as world clocks: either in a small box when you point at the date, or on the page under it. Found a bug or have an idea? Cogwheel icon → Feedback. Pick what kind it is, answer the short questions and press Send; it works without an account too.

Calendar & reminders

Click the calendar icon (or press c). Pick a day, type an event, optionally set a time, a reminder and a repeat, and press Add. To change an event afterwards, press ✎ on it: the same form then holds its name, day, time, reminder and repeat; press Save, or Cancel to leave it as it was. Days with events have a dot, and the number on the icon is today's events. A reminder shows as a notification in the bottom-right corner and stays until you dismiss it (all-day events count as 09:00). Reminders only fire while this page is open in a tab. Games of your ★ sports favorites appear on their day by themselves (click one to open the game); they are not saved with your own events.

Repeating events and birthdays: choose a repeat when you add an event, or press ↻ on an existing one to step through Once, Birthday, Yearly, Monthly, Weekly, Daily. A birthday comes back every year; put the birth year in its name (“Anna 1990”) and it also shows the age.

Calendars from elsewhere (Settings → Calendar → Calendars from elsewhere). There are two ways, and you can use both:

  • Import an .ics file: copies the events into your own calendar, once. You first see what was found and how many there is room for (the calendar holds 300 events of your own). Repeating events keep repeating, one-time events older than a month are left out, and events you already have are skipped. Afterwards they are yours: change the repeat or delete them like any other event. Good for a school term, a sports schedule or moving over from another calendar.
  • Follow a calendar by its address: paste the calendar’s .ics address and press Follow. Its events show next to yours with the calendar’s name after them, and are read again every half hour, so changes made in the other calendar turn up here by themselves. They are not copied and cannot be changed here. You can give each followed calendar a name and a reminder for all its events, and follow up to four. This needs you to be signed in.

Where to find the address: Google Calendar: Settings → click the calendar under “Settings for my calendars” → Integrate calendar → Secret address in iCal format. Outlook.com: Settings → Calendar → Shared calendars → Publish a calendar → the ICS link. Apple iCloud: share the calendar as a Public Calendar and copy the link. The file for a one-time import is in the same places (Google: Settings → Import & export → Export). A secret address lets anyone who has it read that calendar, so treat it like a password; it is saved with your settings and used only to read the calendar.

Taking your events elsewhere: in the same place in Settings, Download my events as an .ics file saves your own events, with their repeats and reminders, as a file that Google Calendar, Outlook and Apple Calendar can import. Calendars you follow and the special days are not in it.

Good to know: times are shown in your own time zone. An event that lasts several days is shown on its first day with the last day in its name. “Every second week”, an end date and skipped days are followed; rarer rules (such as “the last Friday of every third month”) are simplified.

Special days (Settings → Calendar): have the calendar mark big days (Christmas, Easter…), smaller days (Valentine's, Mother's and Father's Day, Halloween…), the public holidays of the countries you tick (red dates), seasons and clock changes, full moons, week numbers and your payday. They are worked out for every year by themselves. Hover or click a day to read them, and tick the ones you want a reminder for.

Next up: the small line under the date at the top of the page is the next thing in your calendar; click it to open that day. Its color is under Settings → Appearance.

Notifications & summary

Small cards appear in the bottom-right corner for: the same story from several of your sources within two hours, a headline with one of your highlight words, a stock on your list moving fast or far, a ★ streamer going live, a ★ team's game starting, scoring and ending, new mail, and calendar reminders. Click a card to open it, ✕ to dismiss. The bell in the menu box keeps the last 30, and its number is how many you have not looked at; opening it clears the number. Hover the mail tile to see your latest unread subjects. Everything can be turned on or off and tuned in Settings → Notifications, including the ping sound and whether to also send desktop notifications (which also keeps news, stocks, sports and Twitch updating while the tab is in the background).

Good to know: a card goes away by itself after 20 seconds, counted only while you are looking at the page, so one that arrived while the tab was in the background is still there when you come back. The ping can only play once you have clicked somewhere on the page; that is a rule of the browser. Heard something and saw nothing? Settings → Notifications ends with the last 5 notifications and alarms on this device, each with its reason and whether it made a sound.

On all your devices: pressing “x new”, opening a post, opening the bell and clearing its history are saved to your account. Do it on the computer and the phone shows the same within a minute, and nothing is announced twice.

By email: tick Also send them to my email to get the same notifications in your connected Gmail inbox, everything from a five-minute stretch in one email. It is off until you switch it on, needs an inbox set up under Mail, and only works while this page is open in a tab.

Summary: one small window with what happened lately. Open it any time from the cogwheel menu or with b. Everything about it is set under Settings → Summary:

  • When it opens by itself: never, on the first visit of the day, when you come back after being away, or both. You choose how long “away” is (30 minutes to 8 hours); away means the page was closed or its tab was in the background for that long.
  • How far back it looks: the last 6, 12 or 24 hours, or the last 2 days.
  • What is in it: weather and warnings, today in your calendar, top stories, Telegram, Reddit, biggest stock movers, mail, who is live on Twitch, ★ streamers who were live while you were away, TV episodes of your shows, sports results and sports coming up. Tick the parts you want and put them in your own order with ▲ ▼. A part with nothing to show is left out by itself.
  • Narrowing a part down: press Choose… on a part to pick which news sources, Telegram channels, subreddits or sports it uses, or to keep it to your ★ channels and ★ teams only. New sources you add later are included by themselves.
  • How it looks: a list, cards side by side, or a compact version, and how many items each part shows at most (3 to 15).

Hover previews: rest the mouse on a news headline or Telegram post to see its picture and text without opening it. Stocks: click a stock to see its chart plus recent news and comments about it.

Wallpaper

Open Settings → Wallpaper. Click Choose image to pick a picture, then choose how it should fit the screen: Fill, Fit, or Original size. Press Reposition to drag the image where you want it, then press Done.

Colors, text size & layout

Settings → Appearance covers the theme, every color, overall text size, the glow background and the shadows. At the bottom, Signal colors per box changes the green and red in Stocks, the live dot in Twitch and the live red and icons in Sports, each with a strength slider to tone it down.

To move or resize the boxes themselves, click the cogwheel icon and choose Edit. Each box then shows small buttons: ◀ / ▶ move it earlier or later, W− / W+ make it narrower or wider, T− / T+ change that box's own text size, and (on lists) H− / H+ show fewer or more rows. You can also drag a box by its title. Click Done in the same menu to finish. On a phone the boxes sit in one column, so the arrows point up and down (▲ / ▼) and the width buttons are left out.

Watching while you browse

Open a Twitch stream or a YouTube video and press Dock on the left. It keeps playing in a strip on the left side while you use the rest of the site. You can dock up to 3 at once, and drag the edge of that strip to resize it. Hover a docked player for its Chat and close buttons; drag the bottom or right edge of the chat to resize it (double-click an edge to reset). To have chat open by itself when you dock a stream, tick it in Settings → Twitch.

Account & privacy

Under Settings, the Account sections are:

  • Password: set a new one (typed twice). If you forget it, click the person icon, then Forgot password?, and a reset link is emailed to you.
  • Sign-in activity: every device and browser signed in to your account right now and the latest sign-ins, with a button to sign out everywhere else. You can also be emailed the first time a new browser signs in (needs an inbox under Mail).
  • Delete account: removes the account and everything saved in it, for good.
  • Backup: downloads all settings, sources, notes and layout as a file you can restore later.

Everything you set up is private to your own account — nobody else using this site can see it. It is saved to the account and follows you to every device: settings, sources, bookmarks, notes, calendar, timers, world clocks, and what you have already seen and opened. Changes made on one device reach the others within a minute, and two devices changing different things never overwrite each other. The full privacy policy says what is stored and why. To run the site, it counts how long the page is open and how often each kind of button is used per account; never what you read, type, search or save. Each visit to the page, signed in or not, is also noted with its IP address, country and browser; that log is kept for 90 days and only the site owner can see it. Text you translate in the search bar goes to the MyMemory translation service, and radio stations are played straight from the stations' own servers. A bookmark set to show “the site's own icon” fetches that icon from the site itself.
